# Insurance Data Analysis

## Objective
Analyze an insurance dataset to understand cost drivers and generate a PDF report with visual insights.

## Dataset
Synthetic insurance dataset with:
- Age
- Gender
- BMI
- Number of children
- Smoking status
- Region
- Insurance charges

## Key Analysis
- Average charges by smoking status
- Distribution of insurance charges
- Regional comparison of charges
- Relationship between BMI and charges

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- ReportLab

## Output
- Automated PDF report generated from Python
- Visualizations exported as images

## Files
- `Insurance_Analysis.ipynb` – Full analysis and code
- `Insurance_Report.pdf` – Final report
- `charges_by_smoker.png` – Chart
- `charges_distribution.png` – Chart
